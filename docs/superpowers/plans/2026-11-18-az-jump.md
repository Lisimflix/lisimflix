# A–Z Rail Jumps Within the Full List Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Choosing a letter on the library A–Z rail scrolls to that letter inside the whole listing, with scrolling up and down both loading titles and the count staying the listing's total.

**Architecture:** `listItems` keeps its keyset cursors. `from` becomes a start position instead of a filter; a first page at a letter also returns `offset` (titles before it), and title-sorted pages return a `prevCursor` that loads the page before. The web grid holds one contiguous loaded window at `start` inside a list sized from `total`, renders placeholders outside it, scrolls to `offset` on a jump and loads both ways.

**Tech Stack:** Go standard library + `modernc.org/sqlite` (server), React + TypeScript, Playwright (web). No new dependencies.

**Spec:** [`docs/superpowers/specs/2026-11-18-az-jump-design.md`](../specs/2026-11-18-az-jump-design.md) (approved design), with the main spec [`2026-10-24-lisimflix-design.md`](../specs/2026-10-24-lisimflix-design.md) §5.1–5.2 (browsing), §8.2–8.3 (contract changes). Contract: [`docs/contracts/openapi.json`](../../contracts/openapi.json) (CTR-2, `listItems`). Related plans: [LIB-2c](2026-10-29-lib-2c-catalogue-api.md) (cursors, decision 8), [UI-2](2026-10-28-ui-2-browse-to-play.md) (grid, decision 12).

## Global Constraints

- Cursors stay opaque, at most 512 bytes (LIB-2c decision 8); a cursor over the limit falls back to the item ID only, as today.
- `total` on the first page only (no cursor), null on later pages; it no longer depends on `from`.
- `prevCursor` is only ever non-null in title order; every other order returns null.
- Existing `nextCursor` cursors keep working (cursor body version stays `1`).
- The contract stays the authority: OpenAPI, Go types, fixtures and the generated `schema.d.ts` change in the same PR (spec §8.2–8.3); `schema.d.ts` is regenerated, never hand-edited.
- No personal hosts, paths or library details in the PR or tests.

## Review Focus

1. **A scan adds titles while the viewer is jumped:** the 5 s poll must not replace a window that doesn't start at 0; only the count updates. Test in Task 3 (`azJumpSurvivesScanPoll`).
2. **Fast scrolling up through placeholders:** one upward load at a time, no duplicated or missing cards. Test in Task 3 (`azScrollUpLoadsOnePageAtATime`).
3. **Tapping letters quickly:** a late reply for an older letter is dropped. Test in Task 3 (`azLateReplyForOldLetterIsDropped`).
4. **Resizing after a jump** (columns change): index-to-row mapping stays consistent and the jumped card stays on screen. Test in Task 3 (`azJumpKeepsCardOnResize`).
5. **Keyboard focus near the unloaded region:** arrow keys never land on a placeholder. Test in Task 3 (`azArrowKeysSkipPlaceholders`).
