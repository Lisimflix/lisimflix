**Goal:** Let the M1 viewer sign in, see the configured movie, and watch its original stream in the browser.
**Architecture:** A small React app talks to the CTR-1 API through one typed, same-origin client. The
player is a native `<video>` on the server's `contentUrl`, with heartbeats and cleanup tied to the
component's lifetime. Tests run the production bundle (`vite preview`) in installed Chrome against
a Playwright route fake built from the shared CTR-1 fixtures, plus a short real H.264 clip.
**Tech Stack:** React 19.3.1, TypeScript 5.9.3, Vite 8.3.5, `@playwright/test` 1.64.1, all already
pinned by CTR-1. No new dependencies.
**Spec:** [Design §§5, 6, 9.3, 9.4](../specs/2026-10-24-lisimflix-design.md); feature **UI-1** (P0 / G1);
acceptance inputs MOVIE-01–03, proven only through integration (#19).

## Global constraints

- M1 plays one complete 1080p SDR H.264 MP4 at its original encoded quality, with no remux or re-encode.
- Final clients are Chrome and Firefox on Linux, Windows and macOS. Browser automation here does not
  certify those six targets; #19's full runs do.
- Trusted-LAN plain HTTP with local username/password. No service worker, public domain, provider
  account or third-party CDN. **Plain HTTP is not a secure context**, so `crypto.randomUUID()` is
  unavailable; idempotency keys use `crypto.getRandomValues()`.
- Passwords, CSRF tokens and grants never go into `localStorage`/`sessionStorage`, logs or any URL
  other than the server's own `contentUrl`.
- The production bundle contains no fixture code: fixtures live only in `web/tests/`.
- Never commit media. The test clip is generated locally and passed by path.

## Changes from revision 1

Revision 1 (2026-10-25) predates CTR-1's merge and the #18/#20 planning gates.

1. **Contract as merged (#8):** `movies()` unwraps `MovieList.items`. Login also needs `X-CSRF-Token`,
   so the app reads `/auth/session` first. Logout rotates the token, so the app re-reads the session
   before showing the form again.
2. **#20's dead-session 409:** a start answered `409 idempotency_conflict` drops its key, and the next
   Play uses a fresh one. Only a network failure or 5xx keeps the key for a retry.
3. **#20's heartbeat rules:** sequences start at 1 and only increase. `410 playback_expired`, `404` or
   `401` ends playback with a retryable message; a network failure or 5xx is retried by the next tick.
4. **No `baseUrl` override:** the client only uses relative paths, which removes the cross-origin
   override case. The client also refuses a `contentUrl` outside `/api/v1/playback/sessions/`.
5. **No `StrictMode`:** its development double-mount would stop the live playback session.
6. **Tests run the production bundle** (`vite preview`), not the dev server, so they prove what ships.
7. **New cases:** `deadSessionKeyStartsAgainWithFreshKey` and `expiredSessionShowsPlayAgain`.
   `lateStartCannotReplaceCurrentMovie` moves to Task 1, since `M1App` owns it.
8. **`.gitignore`:** adds Playwright output and `*.mp4` (shared-file edit, below).

## Review focus

1. Retry rules for the idempotency key: same key after a network failure or 5xx, fresh key after 409 or any other answer.
2. Late responses: a start that resolves after sign-out, or after a newer action, is stopped and never shown.
3. Heartbeats keep running for a full movie, never change `src`, and stop on end, logout, unmount and page close.
4. An autoplay rejection leaves a usable Play button, not a spinner.
5. Fixture success is labelled module proof only.

```ts
import { readFileSync } from "node:fs";
import type { Page, Route } from "@playwright/test";

// Test-only stand-in for the M1 server. Bodies come from the shared CTR-1 fixtures.
const fixture = (name: string) =>
  JSON.parse(readFileSync(new URL(`../../testdata/contracts/m1/${name}`, import.meta.url), "utf8"));

export const PASSWORD = "fixture-only-password";

export interface Call {
  method: string;
  path: string;
  csrf: string | undefined;
  key: string | undefined;
  body: unknown;
}

type Override = (route: Route, call: Call) => Promise<boolean> | boolean;

export class FakeAPI {
  calls: Call[] = [];
  signedIn = false;
  overrides: Override[] = [];
  private sessionCount = 0;

  constructor(private readonly clip?: Buffer) {}

  static async attach(page: Page, clip?: Buffer): Promise<FakeAPI> {
    const api = new FakeAPI(clip);
    await page.route("**/api/v1/**", (route) => api.handle(route));
    return api;
  }

  of(method: string, suffix: string): Call[] {
    return this.calls.filter((c) => c.method === method && c.path.endsWith(suffix));
  }

  private async handle(route: Route) {
    const req = route.request();
    const url = new URL(req.url());
    const call: Call = {
      method: req.method(),
      path: url.pathname,
      csrf: req.headers()["x-csrf-token"],
      key: req.headers()["idempotency-key"],
      body: req.postData() ? JSON.parse(req.postData()!) : undefined,
    };
    this.calls.push(call);
    for (const override of this.overrides) if (await override(route, call)) return;

    const json = (status: number, body: unknown) => route.fulfill({ status, contentType: "application/json", body: JSON.stringify(body) });
    const auth = fixture("authenticated.json");
    const anon = fixture("anonymous.json");
    const error = (status: number, code: string) => json(status, { code, message: `fixture ${code}`, requestId: "req-fixture" });

    if (call.method !== "GET" && call.method !== "HEAD") {
      const expected = this.signedIn ? auth.csrfToken : anon.csrfToken;
      if (call.csrf !== expected) return error(403, "csrf_failed");
    }
    if (call.path === "/api/v1/auth/session") return json(200, this.signedIn ? auth : anon);
    if (call.path === "/api/v1/auth/login") {
      const { username, password } = call.body as { username: string; password: string };
      if (username !== auth.viewer.username || password !== PASSWORD) return error(401, "unauthenticated");
      this.signedIn = true;
      return json(200, auth);
    }
    if (!this.signedIn) return error(401, "unauthenticated");
    if (call.path === "/api/v1/auth/logout") {
      this.signedIn = false;
      return route.fulfill({ status: 204 });
    }
    if (call.path === "/api/v1/movies") return json(200, fixture("movies.json"));
    if (call.path === "/api/v1/playback/sessions") {
      const id = `play-fixture-${++this.sessionCount}`;
      return json(201, { ...fixture("playback.json"), id, contentUrl: `/api/v1/playback/sessions/${id}/content?grant=g-${id}` });
    }
    if (call.path.endsWith("/heartbeat")) return route.fulfill({ status: 204 });
    if (call.path.endsWith("/content")) {
      if (!this.clip) return error(503, "source_unavailable");
      // Byte ranges as the real server sends them; browsers need them to seek.
      const range = /^bytes=(\d+)-(\d*)$/.exec(route.request().headers()["range"] ?? "");
      if (!range) return route.fulfill({ status: 200, contentType: "video/mp4", headers: { "Accept-Ranges": "bytes" }, body: this.clip });
      const start = Number(range[1]);
      const end = range[2] ? Math.min(Number(range[2]), this.clip.length - 1) : this.clip.length - 1;
      return route.fulfill({
        status: 206,
        contentType: "video/mp4",
        headers: { "Accept-Ranges": "bytes", "Content-Range": `bytes ${start}-${end}/${this.clip.length}` },
        body: this.clip.subarray(start, end + 1),
      });
    }
    if (call.method === "DELETE") return route.fulfill({ status: 204 });
    return error(404, "not_found");
  }
}
```

```ts
import type { components } from "./schema";

export type AuthState = components["schemas"]["AuthState"];
export type Movie = components["schemas"]["Movie"];
export type PlaybackSession = components["schemas"]["PlaybackSession"];
type ErrorCode = components["schemas"]["APIError"]["code"];

// status 0 / "network_error" means no API response (offline, aborted or not JSON).
export class ApiError extends Error {
  constructor(
    readonly status: number,
    readonly code: ErrorCode | "network_error",
    message: string,
  ) {
    super(message);
  }
}

export interface M1Client {
  session(signal?: AbortSignal): Promise<AuthState>;
  login(username: string, password: string, signal?: AbortSignal): Promise<AuthState>;
  logout(signal?: AbortSignal): Promise<void>;
  movies(signal?: AbortSignal): Promise<Movie[]>;
  start(movieId: string, key: string, signal?: AbortSignal): Promise<PlaybackSession>;
  heartbeat(id: string, sequence: number, signal?: AbortSignal): Promise<void>;
  stop(id: string): Promise<void>;
}

// Random opaque key. crypto.randomUUID() needs a secure context, and M1 serves plain LAN HTTP.
export function newIdempotencyKey(): string {
  const bytes = crypto.getRandomValues(new Uint8Array(16));
  return Array.from(bytes, (b) => b.toString(16).padStart(2, "0")).join("");
}

// Same-origin only: relative paths, so a page can never be pointed at another host's API.
export function createClient(): M1Client {
  let csrfToken = "";

  async function call<T>(method: string, path: string, init: { body?: unknown; headers?: Record<string, string>; signal?: AbortSignal; keepalive?: boolean } = {}): Promise<T> {
    const headers: Record<string, string> = { Accept: "application/json", ...init.headers };
    if (method !== "GET") headers["X-CSRF-Token"] = csrfToken;
    if (init.body !== undefined) headers["Content-Type"] = "application/json";
    let res: Response;
    try {
      res = await fetch(path, {
        method,
        headers,
        body: init.body === undefined ? undefined : JSON.stringify(init.body),
        credentials: "same-origin",
        signal: init.signal,
        keepalive: init.keepalive,
      });
    } catch (err) {
      if (init.signal?.aborted) throw err;
      throw new ApiError(0, "network_error", "Can't reach the server.");
    }
    if (res.status === 204) return undefined as T;
    const data = await res.json().catch(() => undefined);
    if (!res.ok) {
      const code = typeof data?.code === "string" ? (data.code as ErrorCode) : "network_error";
      const message = typeof data?.message === "string" ? data.message : `Request failed (${res.status}).`;
      throw new ApiError(res.status, code, message);
    }
    if (data === undefined) throw new ApiError(res.status, "network_error", "Unexpected server response.");
    return data as T;
  }

  async function auth(promise: Promise<AuthState>): Promise<AuthState> {
    const state = await promise;
    csrfToken = state.csrfToken;
    return state;
  }

  return {
    session: (signal) => auth(call("GET", "/api/v1/auth/session", { signal })),
    login: (username, password, signal) =>
      auth(call("POST", "/api/v1/auth/login", { body: { username, password }, signal })),
    logout: (signal) => call("POST", "/api/v1/auth/logout", { signal }),
    movies: async (signal) => (await call<components["schemas"]["MovieList"]>("GET", "/api/v1/movies", { signal })).items,
    start: async (movieId, key, signal) => {
      const session = await call<PlaybackSession>("POST", "/api/v1/playback/sessions", {
        body: { movieId },
        headers: { "Idempotency-Key": key },
        signal,
      });
      // The contract makes contentUrl same-origin and relative; never point the player anywhere else.
      if (!session.contentUrl.startsWith("/api/v1/playback/sessions/")) {
        throw new ApiError(502, "internal_error", "Unexpected server response.");
      }
      return session;
    },
    heartbeat: (id, sequence, signal) =>
      call("POST", `/api/v1/playback/sessions/${encodeURIComponent(id)}/heartbeat`, { body: { sequence }, signal }),
    // keepalive lets the stop survive page close; the server's idle expiry is the backstop.
    stop: (id) => call("DELETE", `/api/v1/playback/sessions/${encodeURIComponent(id)}`, { keepalive: true }),
  };
}
```

`web/src/player/M1App.tsx`:
```tsx
import { useEffect, useRef, useState, type FormEvent } from "react";
import { ApiError, newIdempotencyKey, type M1Client, type Movie, type PlaybackSession } from "../api/client";
import { VideoPlayer } from "./VideoPlayer";

type View =
  | { name: "loading" }
  | { name: "login"; error?: string }
  | { name: "ready"; username: string; movie: Movie | null; error?: string }
  | { name: "preparing"; username: string; movie: Movie }
  | { name: "playing"; username: string; movie: Movie; session: PlaybackSession };

function message(err: unknown): string {
  return err instanceof ApiError ? err.message : "Something went wrong.";
}

export function M1App({ client }: { client: M1Client }) {
  const [view, setView] = useState<View>({ name: "loading" });
  // Each load/start takes a new generation; a late response from an older one is dropped.
  const generation = useRef(0);
  // Kept for a retry of the same start; replaced after any answer that settles it.
  const startKey = useRef<string | null>(null);

  async function loadMovies(username: string, signal?: AbortSignal) {
    const gen = ++generation.current;
    try {
      const movies = await client.movies(signal);
      if (gen === generation.current) setView({ name: "ready", username, movie: movies[0] ?? null });
    } catch (err) {
      if (signal?.aborted || gen !== generation.current) return;
      if (err instanceof ApiError && err.status === 401) setView({ name: "login" });
      else setView({ name: "ready", username, movie: null, error: message(err) });
    }
  }

  useEffect(() => {
    const abort = new AbortController();
    client
      .session(abort.signal)
      .then((state) => {
        if (state.authenticated && state.viewer) return loadMovies(state.viewer.username, abort.signal);
        setView({ name: "login" });
      })
      .catch((err) => {
        if (!abort.signal.aborted) setView({ name: "login", error: message(err) });
      });
    return () => abort.abort();
  }, [client]);

  async function onLogin(event: FormEvent<HTMLFormElement>) {
    event.preventDefault();
    const form = new FormData(event.currentTarget);
    try {
      const state = await client.login(String(form.get("username")), String(form.get("password")));
      if (state.authenticated && state.viewer) await loadMovies(state.viewer.username);
      else setView({ name: "login", error: "Sign-in failed." });
    } catch (err) {
      setView({ name: "login", error: message(err) });
    }
  }

  async function onPlay(username: string, movie: Movie) {
    const gen = ++generation.current;
    startKey.current ??= newIdempotencyKey();
    setView({ name: "preparing", username, movie });
    try {
      const session = await client.start(movie.id, startKey.current);
      if (gen !== generation.current) {
        void client.stop(session.id).catch(() => undefined);
        return;
      }
      startKey.current = null;
      setView({ name: "playing", username, movie, session });
    } catch (err) {
      if (gen !== generation.current) return;
      // Only an unanswered or server-side failure may repeat the same request.
      const retrySame = err instanceof ApiError && (err.status === 0 || err.status >= 500);
      if (!retrySame) startKey.current = null;
      if (err instanceof ApiError && err.status === 401) setView({ name: "login" });
      else setView({ name: "ready", username, movie, error: message(err) });
    }
  }

  async function onLogout() {
    ++generation.current;
    setView({ name: "loading" });
    await client.logout().catch(() => undefined);
    // Logout rotates the CSRF token; fetch the anonymous one before showing the form.
    await client.session().catch(() => undefined);
    setView({ name: "login" });
  }

  if (view.name === "loading") return <main aria-busy="true"><p>Loading…</p></main>;

  if (view.name === "login") {
    return (
      <main>
        <h1>Lisimflix</h1>
        <form onSubmit={onLogin} aria-label="Sign in">
          <label>
            Username
            <input name="username" autoComplete="username" required maxLength={128} />
          </label>
          <label>
            Password
            <input name="password" type="password" autoComplete="current-password" required maxLength={1024} />
          </label>
          <button type="submit">Sign in</button>
          {view.error && <p role="alert">{view.error}</p>}
        </form>
      </main>
    );
  }

  const header = (
    <header>
      <span>Signed in as {view.username}</span>
      <button type="button" onClick={onLogout}>Sign out</button>
    </header>
  );

  if (view.name === "playing") {
    return (
      <main>
        {header}
        <h1>{view.movie.title}</h1>
        <VideoPlayer
          client={client}
          session={view.session}
          onEnd={(error) => {
            ++generation.current;
            setView({ name: "ready", username: view.username, movie: view.movie, error });
          }}
        />
      </main>
    );
  }

  const movie = view.movie;
  return (
    <main>
      {header}
      {movie ? (
        <>
          <h1>{movie.title}</h1>
          <button type="button" disabled={view.name === "preparing"} onClick={() => onPlay(view.username, movie)}>
            {view.name === "preparing" ? "Preparing…" : "Play"}
          </button>
        </>
      ) : (
        <p>No movie is configured.</p>
      )}
      {view.name === "ready" && view.error && <p role="alert">{view.error}</p>}
    </main>
  );
}
```

```tsx
import { useEffect, useRef, useState } from "react";
import { ApiError, type M1Client, type PlaybackSession } from "../api/client";

interface Props {
  client: M1Client;
  session: PlaybackSession;
  // Called once when playback finishes; error is set when it stopped abnormally.
  onEnd: (error?: string) => void;
}

export function VideoPlayer({ client, session, onEnd }: Props) {
  const video = useRef<HTMLVideoElement>(null);
  const [blocked, setBlocked] = useState(false);
  const finish = useRef<(error?: string) => void>(() => undefined);

  useEffect(() => {
    const abort = new AbortController();
    let done = false;
    let sequence = 0;
    const stop = () => {
      if (done) return;
      done = true;
      clearInterval(timer);
      abort.abort();
      void client.stop(session.id).catch(() => undefined);
    };
    finish.current = (error) => {
      if (done) return;
      stop();
      onEnd(error);
    };

    // The server's content URL is fixed for the whole session; renewals never change src.
    const el = video.current!;
    el.src = session.contentUrl;
    el.play().catch((err: unknown) => {
      if (!done && err instanceof DOMException && err.name === "NotAllowedError") setBlocked(true);
    });

    const timer = setInterval(() => {
      sequence += 1;
      client.heartbeat(session.id, sequence, abort.signal).catch((err: unknown) => {
        // A network blip is retried by the next tick; the server allows six missed beats.
        if (done || !(err instanceof ApiError) || err.status === 0 || err.status >= 500) return;
        finish.current(err.status === 401 ? "Your sign-in has ended." : "Playback has ended. Press Play to start again.");
      });
    }, session.heartbeatIntervalSeconds * 1000);

    const onPageHide = () => stop();
    window.addEventListener("pagehide", onPageHide);
    return () => {
      window.removeEventListener("pagehide", onPageHide);
      stop();
      el.removeAttribute("src");
      el.load();
    };
  }, [client, session]);

  return (
    <div className="player">
      <video
        ref={video}
        controls
        playsInline
        onPlaying={() => setBlocked(false)}
        onEnded={() => finish.current()}
        onError={() => finish.current("This movie couldn't be played.")}
      />
      {blocked && (
        <button type="button" onClick={() => void video.current?.play().then(() => setBlocked(false), () => undefined)}>
          Play
        </button>
      )}
    </div>
  );
}
```
